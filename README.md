# Desafio Gene & Embrio

Atividade avaliativa em formato de jogo para a turma 1º A de Fisioterapia (Genética e Embriologia).

- `index.html`: o jogo (abre direto no navegador). Banco de 40 questões, 10 sorteadas por partida.
- `planilha-apps-script.gs`: script da planilha Google que recebe as notas.

Configurações (tempo, tentativas, nota máxima) ficam no bloco `CONFIG` no início do `index.html`.
